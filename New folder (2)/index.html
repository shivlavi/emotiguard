Physiological Correlation & Autonomic Dynamics

Examine how electrodermal skin conductance (EDA/GSR) correlates with cardiac vagal modulation (HRV RMSSD).

Parasympathetic Tone (HRV RMSSD)

The Root Mean Square of Successive Differences (RMSSD) between heartbeats reflects parasympathetic activity mediated by the vagus nerve. Higher RMSSD values typically signify restorative rest and physiological flexibility.

Sympathetic Activation (EDA / GSR)

Galvanic skin conductance measures subtle changes in sweat gland secretion innervated exclusively by the sympathetic nervous system. Acute physiological challenges trigger rapid micro-siemen (µS) spikes.

Academic Project Note on Emotion Recognition

Modern biomedical engineering and affective computing literature recognizes that physiological arousal alone cannot distinguish valence (e.g., excitement vs. anxiety have similar autonomic activation). EmotiGuard adheres to scientific best practices by visualizing telemetry trends without making unverifiable emotional claims.

ESP32 Wearable Firmware & Hardware Integration

Standard pinouts and Arduino C++ sketch to flash your ESP32 board for EmotiGuard.

MAX30102 PPG Sensor (HR & SpO2)

  • • VIN -> ESP32 3.3V
  • • GND -> ESP32 GND
  • • SDA -> ESP32 GPIO 21 (I2C SDA)
  • • SCL -> ESP32 GPIO 22 (I2C SCL)

Galvanic Skin Response (GSR / EDA)

  • • VCC -> ESP32 3.3V
  • • GND -> ESP32 GND
  • • SIG -> ESP32 GPIO 34 (ADC1 Analog In)
  • • Electrodes -> Two fingers / palm

GATT Service Architecture

Service UUID: 0000ffe0-0000-1000-8000-00805f9b34fb
Data Characteristic: 0000ffe1-0000-1000-8000-00805f9b34fb (NOTIFY)
Packet Format: {"hr":75,"hrv":45,"spo2":98.2,"gsr":4.50} (or 8-byte binary)
